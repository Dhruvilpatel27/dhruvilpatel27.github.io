# dhruvilpatel27.github.io

Personal portfolio of Dhruvil Patel, software engineer. Live at https://dhruvilpatel27.github.io/

Built with React (Create React App) and deployed to GitHub Pages from the `gh-pages` branch.

## Run locally

```sh
npm install
npm start          # http://localhost:3000
```

## Deploy

```sh
npm run deploy     # builds and publishes to gh-pages
```

Site content lives in `src/data/profile.js`; components only render it.
